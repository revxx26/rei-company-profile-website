# Hot Trainings & Events revision, 6 October 2026

The homepage section now uses REI's original title. It replaces three generic course cards with a compact date-led list in REI blue. The default view shows five selected courses; Show all reveals thirteen. Seven topic buttons filter the list and reset expanded results. A stable 12px button radius applies in every state. Phones use a two-column agenda with horizontally scrollable topic buttons. No decorative eyebrow or additional imagery was added.

Each course opens a native local dialog with an English overview, published session choices, preferred online/classroom attendance, duration, suggested audiences and course focus. These descriptions explain the subject rather than reproduce an approved syllabus. The enquiry button switches the same dialog to consultation, preserving the course, selected date, attendance preference and duration in the prepared WhatsApp/email message. It sends nothing. Closing or Escape restores document scrolling. Course close buttons stay visible while the dialog scrolls.

View published schedule opens the existing schedule dialog, now displaying the selected original poster directly. All six program groups remain available, covering programs 1–139. Source posters remain in their published Indonesian language; the redesigned interface is English.
